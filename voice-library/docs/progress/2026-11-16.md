## Work completed (actions taken)
- **Planning:** plan mode with the user; plan rev 1 and 2 declined, rev 2 approved; the build-trail skill updated to observe in plan mode.
- **Engineering (voice-library/, 66 commits in the repo, ~3,400 lines of Python, ~2,400 of tests):** import with dedupe; Whisper transcription; Claude labelling with retry; keyword + meaning search; `ask` (Claude parses the question, rerank with Match/Partly/Related, sorting, sound filters); local sound detection; background import jobs; curation (collections, suggestions, review queue, archive); waveform, snippets, related notes; folder/Voice Memos import; opt-in sync.
- **UI:** one-box app with Library, Search, Recording, Import and Needs attention; ivory/slate theme, softened corners, compact hero, collection cards, numbered rows.
- **Bugs found and fixed through real use or tests:** all dates were the export time; `av` 19 broke transcription; audio-metadata date was missed when `moov` follows the audio; "giggling" didn't match "giggle"; a single result got no label; a worker-shutdown race; "null"/"[object]" text on screen; sideways scroll on phones; drag from Voice Memos silently did nothing.
- **Testing:** 206 unit tests; `tools/e2e.js` drives every screen in a real browser (found most of the UI bugs above).
- **Docs:** decision log (34 entries), revisit list (sections A-H), this brief.

## Decisions made
Full reasoning is in `docs/decisions.md`. Highlights: free and local-first (2026-11-12); Python; ~1,000 notes; import from files first; Claude for text only, always on (no switch); seeded, extensible collections; sound tagging right after the speech pilot; one-box UI; filename/audio-metadata dates; defer proper evaluation until the user records clips with known answers; ivory/slate, softer look; import from Voice Memos and opt-in one-way sync; phone as a mirroring web app first, reaching the library through the user's Mac.
