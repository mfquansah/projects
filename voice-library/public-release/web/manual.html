Run these in Terminal on your Mac. Grey boxes can be pasted as they are.

1Start the app (each new Terminal window)

Go to the project:

cd ~/Desktop/projects/voice-library && source .venv/bin/activate

Set your Claude key (paste it when the cursor waits, press Enter, nothing shows):

read -s ANTHROPIC_API_KEY && export ANTHROPIC_API_KEY

Start and open it:

python -m vl.cli serve --open

Keep that window open while you use the app. The page is at 127.0.0.1:8765.

Never paste your API key into chat, a document or a screenshot. If it leaks, delete it in the Anthropic Console and make a new one.

2Stop, and update

  • Stop: press Ctrl+C in the app's window. Search stops too; finished recordings are saved.
  • Update: stop the app, then:
git pull

Start again, then press Cmd+Shift+R in the browser. If a module is missing after a pull:

pip install -r requirements.txt

3Importing

Import page, then Import from Voice Memos: test batch (25 newest), next 100, or all. Newest first.

No pause button yet. To stop safely press Ctrl+C, restart, click the same button. Finished ones are skipped; the unfinished one restarts its step.

Length limit: recordings over 45 minutes (usually meetings) are skipped before anything is copied or sent to Claude. Change it when starting:

You wantAdd to the start command
Over 45 min (default)nothing
Over 60 min--max-minutes 60
No limit--max-minutes 0

Applies to Voice Memos, folders and sync; not to files dragged onto the page.

4Other start-up settings

--port 8766another page address if 8765 is busy
--whisper-model basefaster, less accurate transcription (default small)
--llm-model NAMEwhich Claude writes titles and answers
--name Amayour name in the greeting; saved after the first time

Before starting, in the same window: export VL_HOME=/path keeps the library on another drive.

5Sounds (baby laughing, crying)

python -m vl.cli sounds --limit 3
python -m vl.cli sounds
python -m vl.cli sounds --redo

Try 3 first (it can be slow), then the rest, or --redo to re-check all. 0.30+ is "heard", 0.15 to 0.30 is "possibly".

6How long does each step take?

python -m vl.cli profile --voicememos 3

Times a few recordings in a throwaway library (yours isn't touched). Add --no-claude or --no-sounds to skip a step.

7Search and look from the terminal

python -m vl.cli ask "my baby laughing"
python -m vl.cli status
du -sh ~/VoiceLibrary

status lists counts and any recording that failed, and why.

8Where your things live

  • ~/VoiceLibrary/library.db: transcripts, titles, summaries, collections, sounds, indexes
  • ~/VoiceLibrary/audio/: copies of imported recordings. Originals in Voice Memos are never changed.
  • Back up with Time Machine, or copy the folder.

9If something goes wrong

command not found, No module named vlRun step 1 again (the source part)
ModuleNotFoundErrorpip install -r requirements.txt
Claude isn't connectedSet the key (step 1) in the same window, restart
macOS blocks Voice MemosSettings, Privacy & Security, Full Disk Access, add Terminal, quit (Cmd+Q) and reopen it
Page looks oldCmd+Shift+R
Address already in useThe app is running in another window, or add --port 8766

10Not built yet

  • No pause button for imports (see 3).
  • Sync is built but off, and only runs while the app is open.
  • Collection lists sort newest first only. In search, ask in words: "my longest note about work".
  • Audio never leaves your Mac. Only transcript text and your questions go to Claude.
